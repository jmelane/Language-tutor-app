# Interactive Language Learning Tutor

An AI-powered interactive language tutor with gamification elements.

## Features

*   **Language Support**: Spanish, French, German, Japanese, Italian.
*   **Interactive Chat**: Natural conversation with contextual AI responses.
*   **Real-time Feedback**: Grammar, vocabulary, and syntax analysis.
*   **Gamification**: Points system, badges, levels, and streaks.
*   **Learning Goals**: Personalized goals and tracking.
*   **Modes**: Casual and Structured practice modes.

## Setup

1.  Install dependencies:
    ```bash
    npm install
    ```

2.  Start the development server:
    ```bash
    npm run dev
    ```

## Technology Stack

*   React (Vite)
*   Tailwind CSS
*   Lucide Icons
