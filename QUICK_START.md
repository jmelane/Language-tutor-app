# Quick Start Guide - Language Tutor App

## ⚡ Get Started in 3 Minutes

### 1. Get an API Key (2 minutes)

**Recommended: OpenAI (easiest)**
1. Go to https://platform.openai.com/
2. Sign up (free account)
3. Go to API Keys → Create new key
4. Copy the key (starts with `sk-`)

### 2. Add Your API Key (30 seconds)

Open this file: `src/config.js`

Find this line:
```javascript
apiKey: 'YOUR_OPENAI_API_KEY_HERE',
```

Replace with your key:
```javascript
apiKey: 'sk-your-actual-key-here',
```

Save the file.

### 3. Start Chatting! (30 seconds)

The app should auto-reload. If not, refresh your browser.

Now you can:
- ✅ Chat in 8 languages
- ✅ Get instant feedback
- ✅ Track your progress
- ✅ Set learning goals
